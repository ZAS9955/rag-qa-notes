# RAG 学习问答系统

一个用于学习 RAG（检索增强生成）全链路的问答应用：把自己的学习笔记建成知识库，提问时检索最相关的片段，交由大模型生成**有出处、可溯源**的回答。

**在线访问**：https://rag-qa-notes.app.workbuddy.host/?sharecode=JOVGGN7KB3

## 功能特性

- **知识库管理**：内置 5 篇 RAG 学习笔记（全链路流程、Chunk 分片调参、幻觉排查、工具选型、企业落地方案），首次由发布者登录后自动分块入库；支持粘贴新笔记扩充、一键重建
- **问答对话**：流式输出，答案强制附引用来源
- **检索透视**：右侧面板实时展示本次召回的片段与匹配得分——排查"答非所问"时的第一现场
- **权限隔离**：访客只读可提问；发布者通过 WorkBuddy 账号登录后才能编辑知识库（数据库 RLS 行级安全双重保障，绕过前端也无法写入）

## 技术架构

```
离线：笔记(.md) → 分块(200字/重叠40) → 云数据库 kb_chunks
在线：用户提问 → 关键词检索(IDF加权打分, Top4) → 拼接上下文 → LLM 流式生成 → 答案+引用
```

- 纯前端单页应用（无构建步骤），SDK 由本地文件加载，无外部 CDN 依赖
- 后端使用 WorkBuddy 云服务：云数据库（PostgreSQL + RLS）、免密钥大模型调用、账号登录
- 权限：`kb_chunks` 表匿名只读，INSERT/DELETE 仅限 `authenticated` 角色

## 教学设计说明

- **检索层**采用关键词 bigram + IDF 打分实现（教学简化版）。真实企业 RAG 此处为"问题 Embedding → 向量库近邻搜索"；分块、上下文拼接、生成、溯源环节与真实 RAG 完全一致。替换检索层即可平滑升级到向量方案。
- **幻觉抑制三板斧**实测可验：提示词硬约束（"资料没有就说没有"）、低温生成（temperature 0.2）、强制引用溯源。
- 问知识库里没有的问题（如"怎么做红烧肉"），观察系统是否老实回答"没有相关内容"。

## 本地运行

项目依赖 WorkBuddy 云服务环境（数据库与模型调用），直接用浏览器打开 `index.html` 无法完成问答。请在 WorkBuddy 中打开本项目预览，或访问上方在线链接。

## 修改知识库内容

编辑 `notes/` 目录下的 Markdown 笔记 → 重新生成 `notes-data.js` → 在应用中以发布者身份登录后点「重建知识库」。

## 目录结构

```
├── index.html              # 应用主体（UI + 分块 + 检索 + 生成，含中文注释）
├── notes-data.js           # 由 notes/*.md 自动生成的数据文件
├── workbuddy-cloud-sdk.js  # 云服务 SDK（本地化，避免 CDN 不可达）
└── notes/                  # 知识库源笔记（Markdown）
```
